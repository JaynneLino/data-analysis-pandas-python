# Data Analysis Laboratory (Python & Pandas) 🧪

This repository contains a collection of technical studies and practical implementations focused on data manipulation, exploratory analysis, and visualization.

### 🛠️ Tech Stack & Skills
- **Pandas & NumPy:** Advanced data cleaning, filtering, and transformation.
- **Matplotlib & Seaborn:** Creating statistical and trend charts (Dataviz).
- **Exploratory Data Analysis (EDA):** Identifying patterns and outliers in datasets.
- **SQL Integration:** Connecting Python scripts to database environments.
- **Streamlit:** Developing interactive data dashboards.

### 📂 Structure
- `/pandas`: Core manipulation techniques.
- `/numpy`: Numerical computing and array handling.
- `/dataviz`: Visual storytelling with charts.
- `/eda`: Complete exploratory analysis workflows.
